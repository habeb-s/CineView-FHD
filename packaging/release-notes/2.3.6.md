Recording-safe restarts and the OpenBH PVR components (issue #8).

- Enigma2 is no longer restarted while it records. The online updater installs the package and restarts Enigma2 only when no recording is running (otherwise it asks you to restart later); the package itself never restarts Enigma2 during a recording.
- OpenBH: restores the MovieSelection (PVR) poster and FILE / PATH lines (`LukaPosterXEMC`, `CineViewMoviePath`) and the persistent poster cache (`/media/hdd/poster`, `/tmp` only as fallback), which were missing from the 2.3.4 / 2.3.5 OpenBH packages.
- Installer rollback backups in `/tmp/cineview-before-*` are kept when the package is installed.

Built by the release workflow from the 2.3.5 packages and the repository source (`packaging/release.json`). Skin design unchanged. Rollback: the 2.3.5 packages remain in release v2.3.5.
