# CineView MLA — جرد LiiS8 وخطة مكتبة التصاميم

**التاريخ:** 2026-10-04 · **الفرع:** `dev/mla-openatv` · **الجهاز:** Slot 8 (OpenATV 8.0.1، enigma2 57b7a51)
**المرجع المفحوص:** `enigma2-plugin-skins-liis8fhdplus_2.0_all.ipk`، SHA-256 `9d317401…555c`: 24 ملف XML، بلجن `LiiS8Config`، 103 ملف Python، و14 صورة معاينة من المؤلف.
**الترخيص:** لا ترخيص صريح لملفات XML والصور، وملفان بترخيص Dream/CC-NC، وخطوط Neo Sans وVerdana تجارية. لذلك أخذنا الأفكار الوظيفية فقط. لا يُنقل أي إحداثي أو صورة أو خط أو كود، وكل تصميم مقترح هنا تصميم CineView أصلي على شبكتنا (1920×1080، هوامش 48 px، خط أساس 8 px، خطوط Liberation).
**الحالة:** جرد وخطة فقط. **لا تُنفَّذ أي عائلة جديدة قبل اعتمادك البصري لصفحة المقارنة الخاصة بها.**

## 1. نتائج الهندسة العكسية لـ LiiS8

### 1.1 طريقة التبديل والتحكم
- يحفظ `LiiS8Config` الاختيار، ثم ينسخ `sample/<ID>.xml` فوق `infobar.xml` أو `secondinfobar.xml` أو `channelselection.xml`. بعدها يعيد تحميل السكين إن كان `fastSkinReload` مفعّلًا، وإلا يطلب إعادة تشغيل الواجهة. النسخ ليس ذرّيًا ولا يوجد تراجع.
- **ثلاثة أقسام فقط قابلة للتبديل:** InfoBar (IB-1…IB-5، و«IB-6» يظهر في القائمة بلا ملف)، SecondInfoBar (SIB-1…SIB-4)، ChannelSelection (CH-1…CH-5).
- **EPG وPVR وEventView فيها تصميم واحد لكل منها، بلا أي تبديل.** أما `vertical_EPG.xml` فلا يُحمَّل أصلًا.
- **مفاتيح حيّة** يقرؤها الـ Renderer وقت الرسم:
  - البوستر: يسار ويمين، ونسخة كبيرة 495×330.
  - النجوم: يسار ويمين.
  - backdrop، والشعار.
  - الطقس، مع مزودين: Open-Meteo وMET Norway.
  - بوستر ChannelSelection، وبوستر ونجوم SecondInfoBar.
  - مكان التخزين: تلقائي أو مجلد مخصص.
  - بوسترات الرياضة (TheSportsDB، بمفتاح API).
  - كلمات استبعاد القنوات.
  - «تصحيح بوستر خاطئ»: إدخال العنوان الصحيح يدويًا.
- **إيقاف البوستر يخفيه فقط.** المواضع ثابتة في ملف العيّنة، فيبقى مكان الصورة فارغًا ولا تُعاد هيكلة الشاشة. هذا تحديدًا ما تشترطه أنت ولا يقدّمه المرجع.

### 1.3 مكونات مساعدة لاحظناها (فكرة فقط)
عداد دائري من شريط صور، وحقول وصفية للحدث (مخرج، ممثلون، نوع، سنة، بلد، تقييم)، و«Prime time»، وكاش `/proc` مشترك، وبوستر كبير بتغيير الحجم حيًّا، وbackdrop، وتصحيح يدوي للبوستر.
**عيوب لا نكررها:**
- طلب HTTP داخل `getText()` على خيط الواجهة.
- `eTimer` يُشغَّل من خيط عامل.
- `verify=False`.
- مفاتيح API مضمّنة في الكود.
- ألوان وpanels وصور غير معرّفة: 19 لونًا، و12 panel، وأكثر من 100 صورة مفقودة.
- لا ثيمات.

## 3. ما يستحق إعادة التنفيذ (تصاميم CineView أصلية)
القاعدة: لا نضيف تصميمًا إلا إذا اختلف عن الموجود في **توزيع المعلومات أو الوظيفة**. ما كان مجرد وحدة تُضاف أو تُحذف (مثل فروق IB-1…IB-5) يصبح **خيارًا داخل التصميم** (`options[]`)، لا تصميمًا جديدًا.

| القسم | التصميم المقترح | الفكرة | لماذا هو مختلف فعلًا | المصدر |
|---|---|---|---|---|
| ChannelSelection | **Poster List** | قائمة + لوحة للعنصر **المؤشَّر عليه**: بوستر الحدث الحالي، والتالي وما بعده كبطاقات صغيرة، ونبذة، وصف تقني | معلومات القناة المؤشَّر عليها لا المشغّلة (عيب في LiiS8 CH-1) | مخطط §5 + فكرة CH-1 |
| | **Video First** | قائمة ضيقة على جانب يُختار (يسار/يمين)، والفيديو الحي ظاهر، وبطاقة معلومات صغيرة فوق الفيديو | المشاهدة مستمرة أثناء التصفح | فكرة CH-2/3/5 (الجانب خيار) |
| EPG | **Graphical Plus** | الشبكة + لوحة تفاصيل جانبية للحدث المؤشَّر عليه مع بوستر، تقييم للأفلام فقط، ونبذة | الشبكة في LiiS8 بلا تفاصيل غنية ولا بوستر | مخطط §5 |
| | **Columns** | EPG عمودي أصلي في OpenATV (`EPGvertical`): 4–5 قنوات جنبًا إلى جنب | طريقة قراءة مختلفة (مقارنة القنوات زمنيًا) | فكرة vertical_EPG (غير محمّل في LiiS8) |
| | **Single Cards** | Single EPG بقائمة + بطاقة الحدث (بوستر، الوقت، النوع، النبذة) | التصميم الحالي قائمة فقط | جديد |
| SecondInfoBar | **Agenda** | 3 بطاقات زمنية: الحالي، التالي، وما بعده، لكل منها بوستر وبيانات ونبذة مختصرة | بُعد زمني ثالث غير موجود في تصاميمنا | فكرة SIB-4 |
| | **Signal Lab** | عدادات حقيقية من `FrontendStatus` (SNR dB/%، AGC، BER)، التونر والنوع والقفل، التردد والاستقطاب، bitrate، CAID، بلا بوستر | صفحة تشخيص للمستخدم التقني | فكرة SIB-3/SIB-1 |
| PVR | **Cover Library** | قائمة التسجيلات + غلاف + بيانات الملف (الطول، الحجم، الدقة، القناة، تاريخ التسجيل، النبذة) + مفتاح بوستر PVR | بيانات ملف حقيقية لا مجرد غلاف | مخطط §5 |
| EventView | **Feature** | بوستر كبير + العنوان + الوقت + النوع/السنة + التقييم (للأفلام) + نبذة بصفحات، والتالي كبطاقة صغيرة | التصميم الحالي نصّان متجاوران | جديد |
| InfoBar | **Pulse** | شريط مدمج بعدادات قوسية للإشارة والحدث، وشريط تقني اختياري، ولوحة CAM اختيارية | للمستخدم التقني (فكرة IB-1/IB-2 كخيارات) | فكرة IB |
| | **Slim** | سطر سفلي رفيع (شعار، الحالي، التقدم، التالي) يحجب أقل من 12% من الصورة | الحد الأدنى من الحجب | جديد |
| قسم جديد | **Signal / Service info** | صفحة الإشارة ومعلومات الخدمة (Satfinder/ServiceInformation) بتصميم CineView | مذكورة في المخطط §5 ولم تُنفّذ | مخطط §5 |

**لا نقترح:** نسخًا من IB-1…IB-5 كتصاميم منفصلة، ولا SIB-2 «مواصفات الجهاز» كتصميم مستقل (عدادات RAM/flash/CPU تصبح خيارًا في Signal Lab)، ولا بوسترات رياضة بمفتاح API (سياسة المفاتيح والترخيص)، ولا EPG عمودي يعتمد مكوّنًا غير موجود.

### خيارات (options[]) مقترحة بدل تكرار التصاميم
- حجم البوستر (عادي/كبير) في التصاميم التي تحتمل ذلك.
- النجوم: تشغيل/إيقاف.
- لوحة CAM/ECM: تشغيل/إيقاف.
- الشريط التقني: تشغيل/إيقاف.
- جانب القائمة: يمين/يسار.
- عدد أسطر النبذة.
- backdrop خافت: تشغيل/إيقاف.
كل خيار يُقرأ حيًّا، ويُختبر بتشغيله وإيقافه على الجهاز.

## 4. الشروط الإلزامية لكل تصميم
1. **Posters On / Posters Off:** تخطيطان متكاملان لكل تصميم يدعم البوستر. عند الإيقاف تتحرك العناصر وتتغير أحجامها ومحاذاتها لتملأ المساحة، ولا يبقى صندوق فارغ. يُفرض بفحص آلي: لا عنصر مرئي يقع في منطقة البوستر في وضع Off، ولا فجوة أكبر من حد معرّف. ثم يُتحقق بلقطات الجهاز.
2. **العربي:**
   - متغيرات LTR/RTL، ومحاذاة يمنى للعربي.
   - العناوين بالتقليب السطري (الطريقة المثبتة).
   - صناديق بارتفاع أسطر كاملة (line pitch المقاس 21→24 … 27→30).
   - اختبار بنص عربي طويل لكل تصميم.
3. **الثيمات الست:**
   - رموز ألوان دلالية فقط.
   - صور الحالة لكل ثيم.
   - فحص بقايا navy أقل من 1%.
4. **العقود:**
   - كل شاشة وwidget وrenderer/converter موجود في عقد `openatv-8.0.1-57b7a51`.
   - أي مكوّن جديد نكتبه نحن ويُختبر.
   - لا شيء يُفترض.
5. **الأداء:**
   - لا شبكة ولا `subprocess` في `getText()`.
   - قياس CPU لـ enigma2 مع كل شاشة مفتوحة، ومقارنته بـ Classic.
   - 0 tracebacks و0 أخطاء سكين جديدة.
6. **البيانات الحية:** كل قيمة إشارة أو تردد أو bitrate تُطابق webif وتتغير بتغيير القناة.
7. **الاستقلال:** كل قسم يُختار وحده، وأي تركيبة بين الأقسام تعمل.
